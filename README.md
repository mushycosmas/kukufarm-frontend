# KukuFarm Management System

Frontend-only ReactJS application for poultry farm management.

## Stack

- ReactJS + Create React App
- React Router
- React Bootstrap / Bootstrap 5
- Bootstrap Icons
- Recharts
- Context API
- LocalStorage
- Mock data

## Run

```bash
npm install
npm start
```

Open http://localhost:3000

## Demo Login

Any valid email and any password will log in.

Default:
- Email: admin@kukufarm.co.tz
- Password: password

## Modules

Dashboard, Flocks, Flock Details, Egg Production, Feed Management, Health & Vaccination, Mortality, Sales, Customers, Expenses, Suppliers, Reports, Users & Roles, Settings.

## Future Laravel Integration

API calls are intentionally isolated in `src/services/api.js`. Replace the mock/localStorage operations with Laravel API endpoints when the backend is ready.
